## Source Selection Guide

For each topic, aim for this mix:
- 1-2 high-quality blogs/newsletters (deep analysis)
- 3-5 X/Twitter accounts (breaking news, hot takes)
- 3-5 GitHub repos (technical developments)
- 2-3 Telegram/Discord channels (community sentiment)
- 1-2 YouTube channels (presentations, conferences)
- 1 arXiv query (academic papers)
- 1-2 HN/Reddit queries (community discussion)

Total: 11-20 sources. More than 30 = noise overwhelms signal.
