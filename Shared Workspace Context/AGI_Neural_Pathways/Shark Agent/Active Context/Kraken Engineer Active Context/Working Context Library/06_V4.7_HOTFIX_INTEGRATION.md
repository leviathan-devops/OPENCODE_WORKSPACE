## Critical Hook Architecture

### index.ts Structure

```typescript
export function createSharkHooks(
  guardian: Guardian,
  gateManager: GateManager,
  evidenceCollector: EvidenceCollector,
  peerDispatch: SharkPeerDispatch | undefined,
  stateStore: StateStore,
  messenger: SharkMessenger
): Hooks {
  return {
    event: createSessionHook(gateManager, evidenceCollector, peerDispatch, stateStore, messenger),
    'chat.message': createChatMessageHook(),
    'tool.execute.before': createGuardianHook(guardian),
    'tool.execute.after': (input, output) => {
      createToolSummarizerHook()(input, output);  // FIRST - reduce output
      createGateHook(gateManager, evidenceCollector, peerDispatch)(input, output);  // SECOND - collect evidence
    },
    'experimental.session.compacting': createCompactingHook(gateManager),
    'experimental.chat.system.transform': createSystemTransformHook(gateManager, peerDispatch),
  };
}
```

**CRITICAL:** `tool.execute.after` is an ARRAY of two handlers:
1. `createToolSummarizerHook()` — MUST run FIRST to truncate outputs
2. `createGateHook()` — MUST run SECOND to collect evidence

**If you merge these or change order, you will break token optimization.**

## Session Cleanup Chain

On `session.ended`, **ALL** cleanup functions MUST be called:

```typescript
function handleSessionEnded(
  stateStore: StateStore,
  messenger: SharkMessenger
): void {
  stateStore.cleanup();        // Clear data/versions/watchers Maps
  messenger.cleanup();          // Clear queues/pendingAcks/receivedAcks
  dirCreationAttempted = false;
  resetSystemTransformState(); // Clear lastInjectedGate
  resetGateHookState();        // Clear lastDeliveryBlocked
  setCurrentAgent(undefined);
  clearCurrentAgent();
}
```

**If ANY of these are missing, memory will leak across sessions.**

## Tool Summarizer Hook

Location: `tool-summarizer-hook.ts`

Summarizes large tool outputs to reduce token consumption:
- `grep` → "Found X matches in Y files"
- `ls` → "X entries (showing first 20)"
- `read` → First 100 lines + [truncated]

**This hook MUST run before gate-hook to reduce token usage.**

## Gate Hook Evidence Collection

Location: `gate-hook.ts`

Collects evidence after tool execution and advances gates when criteria met:
- Writes evidence files to `.shark/evidence/{gate}/`
- Validates test results (passRate >= 0.96)
- Blocks delivery if evidence missing

## Memory Optimization Checklist

When implementing firewall patterns, ensure:

- [ ] No new Maps or Sets created on every hook call
- [ ] No console.log/console.error in hot paths
- [ ] Regex patterns are pre-compiled (not on every call)
- [ ] Evidence files use streaming for large writes
- [ ] Cleanup functions are called on session.end

## Anti-Patterns (Will Break Memory Optimization)

1. **Console spam in hooks:**
   ```typescript
   // BAD - console noise
   console.log('[GUARDIAN] Checking...');
   
   // GOOD - silent operation
   // (nothing unless blocking)
   ```

2. **Creating Maps/Sets in hot path:**
   ```typescript
   // BAD - new allocation every call
   const files = new Set<string>();
   
   // GOOD - reuse or pre-compile
   const SOURCE_EXTENSIONS = new Set([...]);
   ```

3. **Regex in hot path without caching:**
   ```typescript
   // BAD - recompile every call
   if (/pattern/.test(text))
   
   // GOOD - pre-compiled
   const PATTERN = /pattern/;
   if (PATTERN.test(text))
   ```
