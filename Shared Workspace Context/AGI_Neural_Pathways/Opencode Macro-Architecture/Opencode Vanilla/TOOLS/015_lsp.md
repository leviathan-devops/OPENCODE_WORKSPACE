# lsp

Interact with Language Server Protocol (LSP) servers for code intelligence.

## Tool Definition

**Tool Name:** `lsp`
**Source:** `vanilla-source/packages/opencode/src/tool/lsp.ts`

## Arguments Schema (Zod)

```typescript
{
  operation: enum             // LSP operation to perform (required)
  filePath: string            // Absolute or relative file path (required)
  line: number                // Line number (1-based) (required)
  character: number           // Character offset (1-based) (required)
}
```

### Operations Enum

```typescript
[
  "goToDefinition",           // Find where a symbol is defined
  "findReferences",           // Find all references to a symbol
  "hover",                    // Get hover info (documentation, type)
  "documentSymbol",           // Get all symbols in a document
  "workspaceSymbol",          // Search symbols across workspace
  "goToImplementation",       // Find implementations of interface/method
  "prepareCallHierarchy",     // Get call hierarchy at position
  "incomingCalls",            // Find functions that call this function
  "outgoingCalls"             // Find functions called by this function
]
```

## What It Does

Provides code intelligence via LSP:

- Navigate to definitions
- Find symbol references
- Get hover documentation
- List document symbols
- Search workspace-wide symbols
- Find implementations
- Analyze call hierarchies

## Permission Required

- `lsp` permission with pattern `*`

## Truncation Handling

No truncation - returns full LSP response as JSON.

## Model-Specific Behavior

**All models:** Available to all models, but requires LSP server for file type

## Example Usage

```json
{
  "tool": "lsp",
  "parameters": {
    "operation": "goToDefinition",
    "filePath": "/path/to/file.ts",
    "line": 10,
    "character": 5
  }
}
```

```json
{
  "tool": "lsp",
  "parameters": {
    "operation": "findReferences",
    "filePath": "src/index.ts",
    "line": 25,
    "character": 10
  }
}
```

## Operation Details

| Operation | Description |
|-----------|-------------|
| `goToDefinition` | Jump to symbol definition |
| `findReferences` | Find all places where symbol is used |
| `hover` | Show type info and docs on hover |
| `documentSymbol` | List all symbols in file |
| `workspaceSymbol` | Search symbols project-wide |
| `goToImplementation` | Find implementations of interface/method |
| `prepareCallHierarchy` | Get entry point for call analysis |
| `incomingCalls` | Functions that call this function |
| `outgoingCalls` | Functions called by this function |

## Key Behaviors

1. **1-based indexing** - Line and character are 1-based (as shown in editors)
2. **LSP required** - File type must have LSP server configured
3. **File must exist** - Returns error if file not found
4. **No results possible** - Operations may return empty arrays

## Output Format

Returns:
- `title`: "operation filepath:line:character"
- `output`: JSON string of results (or "No results found")
- `metadata.result`: Raw LSP results array

## Error Handling

- "File not found: [path]" - File doesn't exist
- "No LSP server available for this file type" - No LSP for extension
