# Testing Strategy - Problem Solving Mode

## Unit Tests

### Layer 1 Tests
- [ ] Produces explicit assumption (not vague)
- [ ] Has 3+ reasoning chain items
- [ ] Success criteria are observable
- [ ] Has confirmation/disproof criteria

### Layer 2 Tests
- [ ] Exact command specified (not "test it")
- [ ] Expected output documented
- [ ] Environment state captured

### Layer 3 Tests
- [ ] Raw evidence copied (not paraphrased)
- [ ] Logs checked (not just API response)
- [ ] Expected vs actual comparison table

### Layer 4 Tests
- [ ] Gap analysis: "Expected X, got Y, therefore Z"
- [ ] Updated hypothesis stated
- [ ] Next action tied to insight

### Layer 5 Tests
- [ ] "What I should have done" documented
- [ ] Pattern extracted (generalizable)
- [ ] Systemic issue identified

### Layer 6 Tests
- [ ] Target environment execution verified
- [ ] Behavior matches requirement
- [ ] No regressions checked

## Integration Tests

- [ ] Layer transitions work correctly
- [ ] Iteration deepens, doesn't skip
- [ ] Evidence chain preserved
- [ ] Debugging chain output is injectable
