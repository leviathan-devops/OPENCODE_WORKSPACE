# EXECUTION SEQUENCE - Building Problem Solving Mode

## Phase 1: Layer 1 Template

**When:** Problem Solving Mode triggered
**What:** Agent produces assumption statement
**Who:** Problem Solving Mode

## Phase 2: Layer 2 Template

**When:** Layer 1 validated
**What:** Agent specifies action and expected output
**Who:** Problem Solving Mode

## Phase 3: Layer 3 Template

**When:** Layer 2 validated
**What:** Agent shows raw evidence
**Who:** Problem Solving Mode (with external tools)

## Phase 4: Layer 4 Template

**When:** Layer 3 validated OR gap found
**What:** Agent analyzes gap and adjusts hypothesis
**Who:** Problem Solving Mode

## Phase 5: Iteration Loop

**When:** Gap found at Layer 3
**What:** Return to Layer 1 with new assumption
**Who:** Problem Solving Mode

## Phase 6: Layer 5-6

**When:** Root cause suspected
**What:** Extract patterns, verify fix
**Who:** Problem Solving Mode
