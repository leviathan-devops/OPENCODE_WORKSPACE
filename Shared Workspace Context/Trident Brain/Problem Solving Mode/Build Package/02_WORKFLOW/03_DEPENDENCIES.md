# DEPENDENCY MAP - Building Problem Solving Mode

## Layer Dependencies

- Layer 1 (Assumption) → Layer 2 (Action): Must state assumption before action
- Layer 2 (Action) → Layer 3 (Evidence): Must predict before observing
- Layer 3 (Evidence) → Layer 4 (Gap): Must show evidence before analyzing
- Layer 4 (Gap) → Layer 5 (Pattern): Must analyze before extracting
- Layer 5 (Pattern) → Layer 6 (Verify): Must learn before confirming

## Iteration Dependency

- Iteration N (Layer 3 gap) → Iteration N+1 (Layer 1 new assumption)

## Key Dependencies

| From | To | Nature |
|------|----|--------|
| Assumption | Action | Constrains what to try |
| Action | Evidence | Defines what to look for |
| Evidence | Gap | Enables analysis |
| Gap | Pattern | Enables learning |
| Pattern | Verification | Guides what to verify |
