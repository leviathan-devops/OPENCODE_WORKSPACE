# Mental Model - Context Synthesis Mode

## One-Sentence Explanation

Context Synthesis Mode is a real-time context condenser that takes the chaos of agent context (T1-T4) and distills it into a focused <2k token thought stream.

## Key Abstraction

**Context as Water, Synthesis as Filter**

Most agents drown in context. Context Synthesis filters it:

1. **Collection = Gathering Water** - From multiple sources (T1-T4)
2. **Scoring = Measuring Pressure** - Urgency × Importance
3. **Compression = Distilling** - Remove impurities, keep essence
4. **Injection = Drinking** - Directly into thought stream

## How To Think About It

Think of Context Synthesis as a **coffee maker**:

1. **Water in** = Raw context (T1-T4)
2. **Filter** = Scoring + Compression
3. **Coffee out** = T0-ready thought stream

The filter (scoring algorithm) determines what gets through and what gets discarded.

The output isn't a summary - it's a **prioritized injection** that preserves decision points and key insights.
