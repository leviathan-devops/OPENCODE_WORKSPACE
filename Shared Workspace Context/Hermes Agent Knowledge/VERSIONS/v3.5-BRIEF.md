## Overview

v3.5 integrates the v2.5 Thread/Fork/Orchestration architecture into the v3.0 foundation, adding sophisticated orchestration capabilities.

### New Primitives

| Primitive | Type | Description |
|-----------|------|-------------|
| **Thread** | Async | Non-blocking subagent dispatch |
| **Fork** | Sync | Blocking subagent (takes over UI) |
| **Orchestration** | Chain | Skill chains with conditional branching |
