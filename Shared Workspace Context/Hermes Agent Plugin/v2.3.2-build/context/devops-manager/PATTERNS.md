# DevOps Patterns

## TDD Pattern
1. Write failing test
2. Write minimal implementation
3. Refactor
4. Verify all tests pass

## Delegation Pattern
1. Define task clearly
2. Delegate to appropriate sub-agent
3. Wait for verification
4. Approve or reject

## Error Recovery
1. Identify root cause
2. Create fix
3. Verify fix with tests
4. Deploy
