## 3. PHASE 0: BUILD-CRITICAL BUG FIXES (4 bugs)

### 3.1 Bug #1 — `secretScan` syntax error (CRITICAL)

**File**: `src/tools/security.ts` line 60  
**Problem**: `export const secretScan=***` — invalid TypeScript  
**Fix**: Replace with proper `tool({...})` definition matching the pattern of other tools in the file.

**Design**:
```typescript
export const secretScan = tool({
  description: "Detect secrets/credentials in code",
  args: {
    path: tool.schema.string().optional().describe("Path to scan"),
  },
  execute: async (args, context) => {
    const target = args.path ?? ".";
    const result = spawnSync("grep", [
      "-r", "-n", "-i", "-E",
      "(api[_-]?key|secret[ly]?|password|token|credential|private[_-]?key|access[_-]?key)",
      target,
      "--include=*.ts", "--include=*.js", "--include=*.json",
      "--include=*.env*", "--include=*.yaml", "--include=*.yml"
    ], { cwd: context.directory, encoding: "utf-8", timeout: 60000 });
    if (result.stdout && result.stdout.trim()) {
      const lines = result.stdout.trim().split("\n").slice(0, 30);
      const redacted = lines.map(line => {
        const colonIdx = line.indexOf(":");
        if (colonIdx !== -1) {
          const pathPart = line.substring(0, colonIdx + 1);
          return `${pathPart} [REDACTED - potential secret detected]`;
        }
        return line;
      });
      return `Potential secrets found (verify manually):\n${redacted.join("\n")}`;
    }
    return `✓ No obvious secrets detected.`;
  },
});
```

**Verification**: `bun build.ts` succeeds (currently fails).

### 3.2 Bug #2 — `imports` path traversal (HIGH)

**File**: `src/tools/analysis.ts` lines 85-87  
**Problem**: `readFileSync(join(context.directory, args.path))` with no bounds check  
**Fix**: Add `resolve()` + `startsWith()` containment check.

**Design**:
```typescript
const fullPath = join(context.directory, args.path);
const resolved = resolve(fullPath);
const allowedRoot = resolve(context.directory);
if (!resolved.startsWith(allowedRoot)) {
  return `Error: Access denied. Path resolves outside project directory.`;
}
const content = readFileSync(resolved, "utf-8");
```

**Verification**: `imports` tool rejects `../../etc/passwd` with error message.

### 3.3 Bug #3 — `grill` tool target mismatch (MEDIUM)

**File**: `src/tools/verification.ts` lines 16-17

**Fix**:

**Verification**: `grill` rejects `../../etc/passwd`; `verify` tool doesn't crash.

### 3.4 Bug #4 — `sast_scan` silent failure (MEDIUM)

**File**: `src/tools/security.ts` line 43  
**Problem**: `npx semgrep` exits silently if npx is unavailable  
**Fix**: Add availability check before semgrep.

**Design**:
```typescript
const npxCheck = spawnSync("npx", ["--version"], { encoding: "utf-8", timeout: 10000 });
if (npxCheck.error || npxCheck.status !== 0) {
  return `SAST unavailable: npx not found. Install Node.js to enable security scanning.`;
}
```

**Verification**: When npx is unavailable, returns clear error message instead of silent failure.

**File**: `src/hooks/tdd-enforcer.ts` lines 30-46

```typescript
if (isSrcFile) {

Write the test file first, then the implementation.`;

```

**Verification**: Attempt to write to a src file without a corresponding test file — should be blocked.

### 4.2 Plan Validator — BUILD_INDEX Schema

**File**: `src/hooks/plan-validator.ts`

**Target**: Validate plan has exact file paths, actual code, test commands, acceptance criteria

**Design**:

### 4.3 Brainstorm Gate — Real Blocking

**File**: `src/hooks/brainstorm-gate.ts`  
**Current**: Stub that blocks edits in ANALYZE phase  
**Target**: 
1. Detect ANALYZE/PLAN phase entry
2. Block ALL file writes until design doc exists at project root
3. Require user approval marker in design doc before advancing phase

**Design**:
```typescript
if (currentPhase === PHASES.ANALYZE || currentPhase === PHASES.PLAN) {
  const designDocPath = join(context.directory, "design.md");
  if (!existsSync(designDocPath)) {
    output.blocked = true;
    output.message = `[BRAINSTORM GATE] Cannot write files in ${currentPhase} phase. Create a design.md first.`;
    return;
  }
  const designContent = readFileSync(designDocPath, "utf-8");
  if (!designContent.includes("[APPROVED]")) {
    output.blocked = true;
    output.message = `[BRAINSTORM GATE] Design doc not yet approved. Add [APPROVED] marker to proceed.`;
  }
}
```

**Verification**: File write in ANALYZE phase without design.md is blocked.
