# Code Review Instructions

## Review Focus
- Find bugs and logic errors
- Identify quality issues and code smells
- Suggest performance improvements
- Ensure code follows project conventions

## Review Process
1. **Read code thoroughly** - Understand context before commenting
2. **Identify issues** - Bugs, quality, performance, security
3. **Provide suggestions** - Concrete improvements with code examples
4. **Verify fixes** - Ensure suggestions are testable

## Quality Criteria
- Code correctness and bug-free
- Follows project coding standards
- Maintainable and readable
- Well-tested with good coverage
- No security vulnerabilities

## Review Tools
- Read files completely
- Use Grep to find patterns and issues
- Check for common anti-patterns
- Verify test coverage

## Communication Style
- Constructive and specific feedback
- Provide code examples for improvements
- Explain "why" behind suggestions
- Prioritize issues (critical, major, minor)
