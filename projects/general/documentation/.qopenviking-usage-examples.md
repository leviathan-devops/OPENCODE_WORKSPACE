# OpenViking Context Integration - Usage Examples

## Quick Start

```bash
# Activate OpenViking integration
source ~/.qwen/activate-openviking.sh
```

## Cross-Terminal Context Flow

### Terminal 1: Working on a project
```bash
# Start coding with Qwen Code
# Previous context automatically loaded
# Save new context automatically
```

### Terminal 2: Continue from Terminal 1
```bash
# Open new terminal
# Run: source ~/.qwen/activate-openviking.sh
# Ask about previous work - auto-retrieved!
```

## Commands and Features

### Manual Context Management
```bash
# Save custom context
python3 -c "
from context_manager import QwenContextManager
manager = QwenContextManager()
manager.save_session_context({'project': 'my-app', 'status': 'in-progress'})
"

# Retrieve context
python3 -c "
from context_manager import QwenContextManager
manager = QwenContextManager()
context = manager.get_relevant_context()
print(context)
"

# Check session count
cat ~/.qwen/shared_context.json | jq '.sessions | length'
```

## Benefits

- 🔄 **Automatic Context Sync**: No manual copying needed
- 🧠 **Collective Intelligence**: All agents learn from each other
- 🎯 **Relevant Retrieval**: Smart context filtering
- 🚀 **Seamless Experience**: One continuous vibecoding session
- 📊 **Session Tracking**: Complete session history across terminals

## Troubleshooting

1. **Context not syncing**: Ensure activate script was sourced
2. **Permissions**: Check terminal can write to ~/.qwen/
3. **Terminal IDs**: Each terminal gets unique ID automatically
